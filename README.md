# HUSH.CORP — сайт-портфолио

Статический сайт-галерея творческой команды. Без сборки и зависимостей:
открывается двойным кликом по `index.html`.

## Как посмотреть

Откройте `index.html` в браузере. Всё.

Если нужен локальный сервер (например, для видео):

```powershell
python -m http.server 8080
# или
npx serve .
```

## Что уже внутри

23 работы: 21 фото/графика + 2 видео, оптимизированные под веб
(фото — до 1800 px по длинной стороне, JPEG q86, с учётом EXIF-поворота).

```
index.html            — страница (hero, работы, о нас, контакты)
assets/
  css/style.css       — стили и адаптив
  js/media.js         — ⚙️ список работ (правится только он)
  js/app.js           — галерея, фильтры, лайтбокс
  media/              — фото (.jpg), видео (.mp4/.mov), постеры
```

Категории: Фото · Видео · Дизайн · Моушн · Брендинг.

## Как добавить или заменить работу

1. Положите файл в `assets/media/` (например `noch.jpg`).
2. Откройте `assets/js/media.js` и добавьте объект в массив `MEDIA`:

```js
{
  title: 'Ночной город',
  category: 'Фото',            // Фото | Видео | Дизайн | Моушн | Брендинг
  year: 2026,
  type: 'image',               // 'image' или 'video'
  src: 'assets/media/noch.jpg',
  ratio: '16/9',               // '1/1' | '4/3' | '3/4' | '16/9' | W/H
  colors: ['#14161c', '#2b3140', '#c8ff00'],
}
```

Видео:

```js
{
  title: 'Промо',
  category: 'Видео',
  year: 2026,
  type: 'video',
  src: 'assets/media/promo.mp4',
  poster: 'assets/media/promo.jpg',  // превью в сетке и в лайтбоксе
  autoplay: false,                   // тяжёлый файл — играет по кнопке
  ratio: '16/9',
  colors: ['#14100f', '#2e1c1c', '#ff5c5c'],
}
```

Порядок объектов = порядок карточек. Если файл не найден, вместо него
рисуется заглушка из палитры `colors` — сайт не ломается.

Фильтры строятся по полю `category`. Если добавляете новую категорию,
добавьте кнопку в блок `data-filters` в `index.html`.

## Про исходники

- **HEIC не использованы.** 6 файлов `IMG_*.HEIC` система не декодирует
  (нет HEIF-расширения). Экспортируйте их в JPG — и я добавлю.
- **`promo.mov` (69 МБ, 2 мин)** — оригинал. Chrome/Edge/Safari играют его,
  Firefox может не открыть. Для полной совместимости лучше перегнать в MP4
  (H.264) любым конвертером.
- Остальные исходники лежат в `C:\Users\david\OneDrive\Рабочий стол\HUSH.CORP`.

## Что умеет

- masonry-сетка 3 / 2 / 1 колонки;
- фильтр по категориям с пересчётом количества;
- лайтбокс: `←` `→` `Esc`, свайпы, клик по фону, ловушка фокуса;
- видео: короткое играет автоматически без звука, тяжёлое — по кнопке;
- анимации появления, зерно, бегущая строка;
- мобильное меню на весь экран;
- уважает `prefers-reduced-motion`.

## Кастомизация

- **Акцентный цвет** — `--accent` в начале `assets/css/style.css`.
- **Шрифты** — Unbounded (заголовки) и Manrope (текст), Google Fonts.
- **Тексты** — в `index.html`: hero, «о нас», контакты, e-mail.
